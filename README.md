Discord Bot : simple RPG

la idea es simple pero funcional, un rpg donde podes combatir contra bot enemigos, contra amigos, mejorar tu equipamiento, etc...

la manera que se controla es con comandos, una vez aparezca el enemigo con el comando /Find Enemy, empezara la batalla.

en este apareceran tus estadisticas, las del enemigos, y diferentes opciones que puedes elegir

- Attack : attacas al anemeigo

- Magic : lo  tipico de un rpg, ataque mas fuertes

- Item : curacion 👌

- Flee : por si estas en apuros puedes escapar de la batalla (contra tus amigos se       cambiaria por Rendirse)

puedes hacer 2 acciones por turno, como atacar y despues curarte

claramente hay bots como este mejores como Undertale RPG, que es de donde se inspira este proyecto final

como todo RPG subiras de nivel y tus estadisticas subiran, como la vida, el ataque, defensa y ademas consegiras nuevas habilidades!, donde podras elegir entre diferentes habailidades que son la magia, puedes cambiar una habilidad de una a la otra, me asegurado de que la gran mayoria esten equilibradas para asi elegir inteligentemente las habilidades

otros comandos del bot son :

- /pvp : retas a un miembro del servidor que eligas, si acepta, empieza la batalla

- /stats : Tus estadisticas o las de un miembro del server

- /equip - desquip : podras equipar y des-equipar tus herramientas y habilidades

- /use : usas items o objetos

- /shop : la tienda nomas, comprar, vender, etc

- /help : el tipico comando por si estas perdido

- etc...
